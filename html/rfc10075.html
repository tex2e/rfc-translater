Abstract
概要

This document defines a new flag, the SNAC Router flag, in the Router Advertisement message that can be used to distinguish configuration information sent by Stub Network Auto-Configuring (SNAC) routers from information sent by transit routers.

この文書は、ルータ広告 (Router Advertisement) メッセージに新しいフラグであるSNACルータフラグを定義します。このフラグは、Stub Network Auto-Configuring (SNAC) ルータが送信する構成情報を、トランジットルータが送信する情報と区別するために使用できます。

1. Introduction
1. はじめに

Per Section 2.1 of [RFC2328], networks can either be transit or stub networks. Transit networks are those capable of carrying data traffic that is neither locally originated nor locally destined.

[RFC2328] のセクション2.1によると、ネットワークはトランジットネットワークまたはスタブネットワークのいずれかになります。トランジットネットワークとは、ローカルで発生したものでも、ローカルを宛先とするものでもないデータトラフィックを運ぶことができるネットワークです。

A Stub Network Auto-Configuring (SNAC) router is an autonomously configuring router that provides IP connectivity between one or more stub networks and one or more transit networks. A common example of a SNAC router is a device that attaches a 6LoWPAN-based network [RFC4919] to a home network, automatically providing IPv6 forwarding between the two networks without explicit operator configuration. This document defines a new IPv6 Neighbor Discovery Router Advertisement (RA) flag, the SNAC Router flag, which SNAC routers use to identify RAs sent by other SNAC routers.

Stub Network Auto-Configuring (SNAC) ルータは、自律的に構成を行うルータであり、1つ以上のスタブネットワークと1つ以上のトランジットネットワークの間のIP接続を提供します。SNACルータの一般的な例は、6LoWPANベースのネットワーク [RFC4919] をホームネットワークに接続し、運用者による明示的な設定なしに、2つのネットワーク間のIPv6転送を自動的に提供するデバイスです。この文書は、IPv6ネイバー探索 (Neighbor Discovery) のルータ広告 (RA) に新しいフラグであるSNACルータフラグを定義します。SNACルータは、このフラグを使用して、他のSNACルータが送信したRAを識別します。

Readers can refer to [AUTO-STUB] for an overview of a set of practices for automatically connecting IPv6 stub networks to transit networks.

IPv6のスタブネットワークをトランジットネットワークに自動的に接続するための一連の実践方法の概要については、[AUTO-STUB] を参照してください。

2. SNAC Router Flag
2. SNACルータフラグ

The SNAC Router flag is bit 6 in the RA Flags Extension Option [RFC5175].

SNACルータフラグは、RA Flags Extension Option [RFC5175] のビット6です。

The SNAC Router flag bit with a value of '1' is reserved for use by SNAC routers. Receipt of an RA with that bit set to '1' indicates that the sending router is a SNAC router. Describing the exact triggers when a SNAC router sets this flag to '1' is out of scope for this document. An example of such considerations is documented in [AUTO-STUB].

値が '1' のSNACルータフラグビットは、SNACルータが使用するために予約されています。このビットが '1' に設定されたRAを受信した場合、送信元のルータがSNACルータであることを示します。SNACルータがこのフラグを '1' に設定する正確な契機については、この文書の範囲外です。そのような考慮事項の例は [AUTO-STUB] に記載されています。

Consistent with Section 4.2 of [RFC4861], devices that do not operate as SNAC routers will not set the SNAC Router flag bit to '1', and devices that do not understand the SNAC Router flag will silently ignore it. This means that setting the flag bit to '1' or '0' should not change the behavior of such devices in any way (other than that it is permissible to log and cache the value of the flag bit as part of normal router advertisement processing, where applicable).

[RFC4861] のセクション4.2と整合して、SNACルータとして動作しないデバイスはSNACルータフラグビットを '1' に設定しません。また、SNACルータフラグを理解しないデバイスは、それを黙って無視します。つまり、フラグビットを '1' または '0' に設定しても、そのようなデバイスの動作は一切変わらないはずです (ただし、該当する場合には、通常のルータ広告の処理の一部として、フラグビットの値を記録およびキャッシュしてもかまいません)。

4. Operational Considerations
4. 運用上の考慮事項

In environments that implement RA-Guard [RFC7113] in a way that filters RAs sent by SNAC routers, devices on the transit network will never receive an RA with the SNAC Router flag bit set to '1'.

SNACルータが送信したRAをフィルタリングする方法でRA-Guard [RFC7113] を実装している環境では、トランジットネットワーク上のデバイスが、SNACルータフラグビットが '1' に設定されたRAを受信することはありません。

5. Security Considerations
5. セキュリティに関する考慮事項

How SNAC routers process RAs is dependent on the SNAC Router flag value.

SNACルータがRAを処理する方法は、SNACルータフラグの値に依存します。

The security considerations of IPv6 Neighbor Discovery are documented in Section 11 (Security Considerations) of [RFC4861]. The addition of the SNAC Router flag does not change these considerations.

IPv6ネイバー探索のセキュリティに関する考慮事項は、[RFC4861] のセクション11 (Security Considerations) に記載されています。SNACルータフラグの追加は、これらの考慮事項を変更しません。
