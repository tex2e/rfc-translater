# HTMLフラグメントの本文混入調査

2026-10-31実施。翻訳JSON 7,709件（RFC 7,703件、旧Draft 6件）を横断検索し、
HTMLタグに似た記述を含む非raw段落416件を抽出しました。
タグの属性・開始位置・終了タグから候補を絞り、42件の公式RFC TXTを参照しました。
HTML自体が不要な混入物なのではなく、原文のサンプルを本文と誤判定していた問題です。

## 修正範囲

25 RFCで、原文の改行・字下げを復元したコードブロック59個をrawにしました。
既存のraw段落・要約・原文のサンプル内容は変更していません。

| 対象 | 修正内容 |
| --- | --- |
| 2397, 6596 | HTML例と、改ページ後に誤結合されていた説明文を分離。説明文の対訳を保持・修正 |
| 5005, 6121, 6787 | 同じ誤結合を起こしていたXML例と説明文を分離。失われていた説明文の訳も補完 |
| 2295, 2368, 2392, 2557, 2731, 2774, 2806, 2936, 3966, 4590, 4709, 5090, 5196, 5222, 5707, 5870, 6068, 7991, 7992, 8297 | 単独タグ、MIME/HTTPのHTML本文、HTML出力例、XML例の一部をコード表示に変更 |

照合元は `https://www.rfc-editor.org/rfc/rfc番号.txt` です。
例: [RFC 2397](https://www.rfc-editor.org/rfc/rfc2397.txt)、
[RFC 5707](https://www.rfc-editor.org/rfc/rfc5707.txt)。
原文にも存在する省略記法・閉じ忘れ・属性の不正な引用符は仕様を勝手に修正せず維持しています。

## 残るタグ表記

修正後のRFCデータには、タグやそれに似た表記を含む非raw段落が360件残ります。
これらは本文中のタグの説明、短いインライン例、プロトコルの変数表記などです。
たとえばRFC 2397の本文中の`<A>`、RFC 5444の`<head>`、RFC 7047の`<table>`は本文のままです。
単独のコードブロックと判定される残存候補は0件です。
この判定は意味理解による網羅保証ではありません。新しい例を見つけたときは原文TXTで確認してください。

## 再発防止

- 完結したHTML/XML例の直後では、改ページ後の説明文を自動結合しません。
- HTMLのvoid要素は、行境界を使って前後の説明から分離します。属性値内の`>`も考慮します。
- 完結したHTML文書内の空行はコード内に保持します。既存のXMLブロックは分割しません。
- 単なるタグの説明やプロトコル変数は翻訳対象に残します。
- `tests/test_html_fragments.py`で改ページ・コード分離・誤検出を検証し、HTML→JSONの往復検証にも修正RFCを追加しました。
- CIで次の読み取り専用検査を実行し、単独のコード候補が非rawで追加されると失敗させます。

```sh
python3 tools/check_html_fragments.py --check --format json
python3 tools/check_html_fragments.py --rfc 2397 6596
```

`inline_or_placeholder`は要手動判断の情報です。これを一括でraw化したり削除したりしないでください。
改行を失った既存データを自動整形する機能は設けていません。公式TXTとの照合が必要です。

## ブラウザでの表示確認（2026-10-31）

対象25 RFCすべてについて、ローカルで生成したHTMLをブラウザで開き、変更した段落とその前後を確認しました。
確認環境は1280×720のデスクトップ表示・ダークテーマです。
コード内のタグが文字列として表示され、等幅フォント・改行・字下げがJSONと一致すること、
説明文の英日対訳がコードの外に表示されることを確認しました。
ブラウザの描画結果とスクリーンショットの両方を確認しています。

その際、HTML例の周辺にもサンプルの本文扱いが残っていることが分かり、次の42段落を追加補正しました。
公式TXTとの照合後にHTMLを再生成し、ブラウザで再読み込みして追加箇所すべてを再確認しました。

| RFC | 追加補正した段落数 | 内容 |
| --- | ---: | --- |
| 2557 | 23 | MIMEヘッダー・境界・Base64データ・HTML本文中の文字列 |
| 4590 | 1 | HTTPレスポンス |
| 4709 | 3 | HTTPリクエストとレスポンス |
| 5090 | 1 | HTTPレスポンス |
| 6596 | 1 | 単独のURL例 |
| 7991 | 9 | HTML出力例に対応するXML入力例 |
| 7992 | 4 | HTML出力例に対応するXML入力例 |

追加分も既存のraw段落は変更していません。取得時のHTTP・MIME・Base64判定、
明示的に導入されたXML入力例の判定を追加し、回帰テストを実施しました。

確認済みRFC: 2295, 2368, 2392, 2397, 2557, 2731, 2774, 2806, 2936, 3966,
4590, 4709, 5005, 5090, 5196, 5222, 5707, 5870, 6068, 6121, 6596, 6787,
7991, 7992, 8297。
