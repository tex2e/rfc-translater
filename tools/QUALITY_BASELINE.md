## 残った欠陥について

**E001 が 0 でも識別子が全て正しいわけではありません。** 自動判定できない分は
W009 として別に計上しています（1,423件）。指標を良く見せないための分離です。

W009 は原文内で同じ綴りが複数の表記で現れるケースです。SMIやC APIの慣習で
以下のように併存します。

```
natInterfaceEntry OBJECT-TYPE SYNTAX NatInterfaceEntry ...
CMSG_DATA() ... what is called the cmsg_data[] member ...
```

訳文には壊れた表記が1つしかないため、どちらに復元すべきか機械的には決定できません。
誤修正を出さないため自動変換の対象外とし、人手またはAIの判断に委ねています。

**W006 の残り 3,374 件は機械変換できない見出しです。** 内訳:

- サ変動詞でないもの — 「オプションを含めます」「曖昧性を乱します」
  （含める・乱すは五段/下一段動詞。体言化に語彙判断が要る）
- 主題の「は」を含む文 — 「パディングフレームは輻輳ウィンドウを消費します」
  （体言止めにすると「Xは〜の消費」となり非文になるため除外）
- 「〜です」「〜できます」で終わるもの — 「共通の語彙が必要です」
  （「共通の語彙の必要性」のような書き換えは意味理解が必要）

## 所見

**RFC7000帯だけE001が修正前から28件と突出して少なく、修正後も272件です**
（他帯は修正前 3,005〜21,314件）。この帯だけ別の手順・別エンジンで処理された
可能性が高く、原因を特定できれば新規翻訳の品質向上に転用できるかもしれません。

## 注意

このlinterは**原文と照合して決定的に判定できる違反のみ**を検出します。
訳語選択の妥当性、文の自然さ、文脈整合性は検出できません。
これらは `.agents/skills/review-translation` によるAIレビューの担当範囲です。
