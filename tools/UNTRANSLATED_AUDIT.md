# 未翻訳の案内文・本文の横断調査

2026-10-31開始。先行する表示修正は`1b8600a40d`としてコミット済みです。
全7,703 RFCの翻訳JSONを対象に、日本語を含まない訳文を調査しています。
当初の優先7 RFC・209段落に続き、全RFCの本文候補も順に確認する範囲へ拡張しました。
この横断調査は継続中であり、全件完了を意味しません。

## 判定方法

`With an input of:`などは、`ja`に英語が残っていたため、画面の左右に英語が表示されていました。
原文と前後の段落を確認し、本文・見出し・説明に日本語を補っています。
RFC2119キーワードの強度と出現数、識別子、箇条書き記号を維持します。
確認順は`tools/rank_rfcs.py`の検査結果と被引用数による順位に従います。

英語のまま残すべきコード、図表、属性値、参考文献、人名・所属は、未翻訳と区別します。
既存訳の一括流用はせず、今回確認した訳文についてのみ、英文が完全に一致する本文候補に適用します。

## 確認できた原因と修正

- 案内文・本文・見出しに英語が残る、または訳文が空：日本語を追加します。
- MIB/YANGソースのDESCRIPTIONなどが本文として分割される：原文のコード領域と照合し、誤分類された段落を`raw: true`・`ja: ""`に戻します。
- LDAPスキーマ、注釈付きCBOR、状態遷移表、メールサンプルなどの改行が失われる：RFC Editorの原文と照合して、行・列・インデントを復元します。
- RFC 6349と7143の説明文が改ページで分断される：それぞれ1段落に結合して訳し直しました。
- RFC 4104のLDAP定義、RFC 3470のXSLT断片と後続の説明文が同一段落に混在する：コードと説明を分離し、説明だけを翻訳しました。
- 著者・貢献者一覧が翻訳されて名前を損なう：確認した一覧を原文表記へ戻しました。

修正前から`raw: true`だった段落は変更していません。
新たにコードへ戻した段落は、空白を除く原文の文字列を維持しています。
段落の結合・分離も、英語の内容を加除せずに行っています。要約は変更していません。

## 再発防止

`tools/check_untranslated.py`は、読み取り専用の未翻訳候補検出ツールです。
本文らしい候補は人が確認し、コード・識別子・書誌情報・人名一覧などの誤検出を区別します。
候補数は未翻訳の確定数ではありません。短い表記や既存訳の誤訳を網羅する検査でもありません。

```sh
python3 tools/check_untranslated.py --format json > /tmp/untranslated.json
python3 tools/check_untranslated.py --rfc 7991 7992
python3 tools/check_untranslated.py --check-guidance --format json
```

CIでは、例の導入文・内容モデルなど、明確な案内文の未翻訳を検出します。
一般の本文候補すべてをエラーとすることは、コード等を誤翻訳する原因になるため避けています。
MIB/YANGの明示的なコード領域、状態遷移表、LDAPスキーマ、注釈付きCBORについても、
原文取得時にコードとして保持する処理と回帰テストを追加しています。

## 検証

修正したRFCごとにJSON構文と翻訳lintを確認し、既存の指摘から増えていないことを比較しています。
既存の`raw`段落の不変性と、コードに戻した文字列の原文との一致も確認しています。
HTMLを生成し、ブラウザで変更箇所の英語・日本語の一致、表示領域、横方向のはみ出し、
コードの等幅表示・エスケープ・改行を確認しています。

現時点でも本文候補は残っています。残件は上記コマンドで再抽出でき、
残存候補の原文確認、日本語の補完、lint、HTML生成、ブラウザ確認を引き続き行います。
